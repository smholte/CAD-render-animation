Pictures are the real app at UI scale 1.5, shown at their own size, from the test crane. ★ = my recommendation (ticked to start with). Tick what 0062 should build, choose below, press Copy and paste the line to the lead.

1 · Improvements (task 0062, point 5)

All sections effort S/M

A separation rule for ui.py: one helper gap(layout) between steps, a boxed header line for every sub-panel, hints in grey text, buttons only inside a step.

Why: Instruction box, settings and button run into each other in every sub-panel; sections 1–7 are only told apart by a thin line.

Could break: Every panel's picture in the guide changes; real-app tests click fixed spots (a gap moves them by pixels).

Cutaway, Logos, Paint faces, X-ray, Cables, CNC, Milling, Hoses, Mechanisms, Tracks, Way covers, People, Trail lines, Clash … (about 20) effort M

Numbered how-to boxes go into a small fold How it works: open on a new project, closed once you have used the function; a switch in Preferences keeps them open.

Why: The boxes take about half of every sub-panel's height (CNC machine: 5 steps before the first button). A user who knows the app scrolls past them every time.

Could break: Guide pictures show the boxes today; tests that count rows below a box.

5 Scene & Render effort M

Order the 12 sub-panels the way the work goes: surroundings (background, weather, vessel motion, vessel at work, props) → light → camera → saved scenes → image size & render → turntable → web 3D. Now: Camera, Image size & render, Saved scenes, Brand kit, Labels, Props, Turntable, Vessel motion, Vessel at work, Watermark, Weather, Web 3D.

Why: Weather and the vessel are part of the surroundings but sit under Watermark and Turntable; Render comes before the scene is finished.

Could break: Order is only registration order and bl_order; guide chapter text; the tour's 'where in the side panel' lines.

5 Scene & Render → 6 Animation effort M

Move Brand kit & logo, Labels, Watermark next to Finishing, Pictures, Music (one 'Video finishing' group in 6). Build the '(6 Animation > …)' cross-references from one table so a move cannot leave a wrong pointer.

Why: Brand kit says '(6 Animation > Finishing)' and Finishing says '(5 Scene & Render)': the two halves of one job sit in two sections. Labels is in 5, Pictures (the same kind of thing) in 6.

Could break: functions.py panel field, ui_test_video.py, ui_test_callouts.py, pictures panel_5_brand / labels / watermark, ~15 text references (props.py, tour.py).

5 Scene & Render effort L

Split section 5 into two sections ('5 Scene' and a new 'Render & output'). Not recommended: section numbers 6, 7 become 7, 8 and about 230 text references ('4 Motion >', '6 Animation >' in props.py, tour.py, ui*.py, the guide) change. Items 3 and 4 plus the workspaces already shorten section 5.

Why: Section 5 is about 5,000 px tall with every fold open.

Could break: Highest: renumbering, every real-app test and guide picture.

All panels effort S

Same words for the same things (pairs found in the panels, I would settle one word each): Remove / Delete / Clear (6 + 3 + 2 buttons: 'Remove selected', 'Delete…', 'Clear chips', 'Clear import cache') → Remove takes a thing out of the project, Clear empties a list or a cache, Delete only for files; Show in folder / Show the folder / Open the logos folder → Show in folder; Add / Make / Use as ('Add cable', 'Make toolpath', 'Use as bit') → Add for a new thing, Use as for picking a part; Build animation / Build & play; Back to CAD / Back to normal / Back to the rules / Defaults → Back to … always with what you go back to; Find / Search ('Find the axes', 'Find hoses', the tree's 'Find'); 'Set-up' / 'Set up'.

Why: The same action has several names, so a button must be learnt each time.

Could break: Tooltips and guide text use the old words; tooltip_report.py, tests that find a button by its text (ui tests).

Logos & stickers, Labels, Camera, Mechanisms, Group list, Render queue effort S

Fix the labels cut off with '…' at the default width: 'Open the logos …' / 'Open the sticke…', 'Draw labels in rend…', Camera header 'Iso front-rig…', 'the rest of the subassem…' (Mechanisms), 'Welded fram…res #F9A800' (group list), 'Animation: Luff and tra…' (queue row). Shorter texts or two lines.

Why: Breaks the layout rule 'no cut-off labels at the default width'.

Could break: Small. Tooltip and guide texts if a label's words change.

3 Looks and every sub-panel effort S

One blue main button per section: sub-panel buttons stay big but grey; only the one thing a section is for is blue (primary()). Today a Looks screen shows five blue buttons at once (Put ticked in new group, Add cut, Add decal, Paint faces, X-ray the selected) while 'Sort parts into groups' – the real step – is grey. 32 primary() calls.

Why: Blue no longer says 'start here'.

Could break: Low; guide pictures show the colours.

Vessel motion, Vessel at work (and likewise Way covers, Drums, Tracks when empty) effort S

When the thing is not there (no sea / no vessel deck chosen) show one line with a button ('Choose the Open sea'), or hide the sub-panel; the workspaces will hide it anyway.

Why: Two sub-panels both show a four-line grey box saying 'pick one under Background & surroundings above'.

Could break: Tour stops open these; the PC check's scene lines.

Top of the Fresing tab effort S

A short 'What's next' card above 1 Import: empty project → 'Import a STEP file'; after import → 'Next: 2 Structure, 3 Looks, then 5 Scene & Render > Render image'; goes away after the first render (a small × also hides it; remembered per project).

Why: After the import the top of the panel only says what was imported; a new user does not know the order.

Could break: New card shifts everything down by ~90 px (tests click fixed spots); one property in props.py.

4 Motion > Poses & exploded views effort S

Give Exploded view its own sub-panel (it belongs with the Assembly sequence step; the Product design workspace shows it, CNC does not).

Why: A pose list and an exploded view are two functions in one sub-panel; a workspace can hide only whole sub-panels.

Could break: functions.py fold fields, panel_4_poses picture.

3 Looks effort S

Move the Manage rule sets fold (Copy, New, Rename, Delete, shared library path, Show the folder) into 'Sorting rules'; keep only the rule-set picker at the top.

Why: A project's first screen in Looks is a rule-set manager, above 'Sort parts into groups'.

Could break: ui_test_rule_sets.py, panel_3_rule_sets picture.

All panels effort S

Quieter hints: the info icon is drawn 100 times and the red error icon 78 times in ui*.py; keep the icon for warnings and errors only and write plain hints as grey text without an icon (saves a line each).

Why: Every hint looks like an alert, so the real alerts do not stand out.

Could break: Low.

Every sub-panel header effort M

A state in every sub-panel header (the layout rule says so; today only Camera, Weather, Vessel motion, Mechanisms, Cables, Drums and Tracks have one). For example 'Cutaway: 2 cuts', 'Logos: 3 decals', 'Paint faces: 4', 'X-ray: off', 'Turntable: 10 s', 'Labels: 2', 'Watermark: on'. Needed for folded sections (point 4).

Why: With sections starting folded, the header must tell what is inside.

Could break: Each header reads a count; draw cost (study 0195 measures the draw).

3 · Client view: how strict is the lock?

Recommendation: (b), with Full access as the unlock (it is your own tool; a client is given the Client view). (c) only if projects go to clients who open the file themselves. The 'Locked in place' per part stays as it is.

4 · Blender's own 'workspaces' tabs

Today the app template leaves Blender's 11 tabs at the top (Layout, Modeling, Sculpting, UV Editing, Texture Paint, Shading, Animation, Compositing, Geometry Nodes, Rendering, Scripting): the Fresing code never touches them. Beside the app's own word 'Workspace' that is confusing, and a client can end up in Sculpting.
