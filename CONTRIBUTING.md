# Contributing

Fresing Render is made by Fresing. Thank you for looking at it.

## What is welcome

**Bug reports and ideas, as issues**: https://github.com/smholte/CAD-render-animation/issues/new/choose

Before you report a bug:

1. Find the **version**: in the app, the Fresing menu at the top shows it ("What's new in 0.2.xxx").
2. Run the **PC check** (Start menu > Fresing Render > "PC check (quick)") and say what it found.
3. Write the **steps** that lead to the problem, what happened and what you expected.

## Never put confidential things in an issue

**This repository is public.** Anything you attach is visible to everyone and may be copied and kept, also after you
delete it.

- **No models** of your own or of a client (STEP, mesh, project files), **no part names, no screenshots or renders of
  them.** The form asks you to tick that your report holds none.
- If the problem only shows with a confidential model, describe it in words, or try to see it with a model of the
  app's own test set (Help > Make test tour project…).
- Company users, and anything that must stay private: use the **private report** link in the issue chooser (it opens
  GitHub's private security report form), not a public issue.

## Code and pull requests: not for now

**Code contributions and pull requests are not taken for now.** The owner keeps the copyright of the program whole, so
that the licence can be handled in one place. A pull request will be closed with a thank-you. If this changes, it
will be written here.

You are free to use the code under its licence (GPL-3.0-or-later, see `LICENSE`), also to make your own version –
with your own name (see the brand note in `README.md`).
